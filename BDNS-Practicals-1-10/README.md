# BDNS Practicals 1-10

This ZIP is organized from the uploaded **BDNS Journal.pdf**, with Practical 1 through Practical 10 separated into folders for easier GitHub upload and exam practice.

## Folder mapping
- Practical 1–3: MongoDB commands
- Practical 4: Java + MongoDB
- Practical 5: PHP + MongoDB
- Practical 6: Python + MongoDB
- Practical 7–9: jQuery/HTML
- Practical 10: JSON

The PHP section in the journal uses the legacy `MongoClient` / `php_mongo.dll` API. The Java section also uses the APIs shown in the journal. These are kept close to the journal so the practical answers match your source material.
